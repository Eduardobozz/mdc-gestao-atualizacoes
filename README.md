# MDC Gestao - atualizacoes

Este repositorio guarda so os instaladores do MDC Gestao (na aba Releases), para o programa se atualizar sozinho nas lojas.
O codigo do programa nao fica aqui.

- Pre-lancamento: versao de teste (so o computador de teste baixa).
